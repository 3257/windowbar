WindowBar / Design study · 01

A quieter place for every window.

Three directions for a single native macOS row. Clear focus, distinct Chrome profiles, and familiar pinned apps — with room to grow.

Mockups · sample data only

01 · Quiet Shelf Recommended

Soft material, a slightly raised focused window, and restrained blue. Titles stay readable; profile names replace repeated app labels.

02 · Work Ribbon

A lower, denser row for many windows. Fine separators and compact type maximize space. Best when the taskbar is always visible.

Maximum density

03 · Floating Dock

A centered, icon-led shelf with short labels and profile avatars. Familiar and playful, with a larger footprint and less room for long titles.

Most Dock-like

Try selecting a window, hovering for a preview, dragging a window to reorder it, right-clicking Chrome, or opening ⋯. These interactions change only this mockup.

Tab reaches every control. Arrow keys move between windows; Enter or Space selects. At high counts, windows keep a minimum target size and scroll horizontally.

Focus without shouting

A focused window gets 30% more width, a subtle surface change, and an accent indicator. Keep the user’s system accent and appearance.

Profile identity is honest

Show a name and initial only when a window’s profile is known. Color is an extra cue, never the only cue. Unknown profiles show “Chrome”.

Calm by default

Small 140–220 ms transitions. No bouncing or mandatory icon magnification. Respect Reduce Motion, Increase Contrast, and Reduce Transparency.

Companion settings

Familiar controls.
One place to tune the bar.

A small native Settings window keeps the taskbar simple. General covers daily behavior; separate pages handle pinned apps, shortcuts, and diagnostics.

Thumbnail permission should be requested only when the user selects thumbnails. Keep title previews available at all times.
